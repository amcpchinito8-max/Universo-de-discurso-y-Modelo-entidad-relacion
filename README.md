El documento describe el sistema de gestión académica para la Unidad Educativa "Juan Vicente González", enfocado en automatizar procesos escolares bajo una política de "cero papel" y soberanía tecnológica. Incluye el universo de discurso, la propuesta de valor social, las reglas de negocio lógicas del sistema, el diccionario de datos de sus entidades relacionales y la definición de las cardinalidades para garantizar la integridad referencial.
